Suggest a book

Help complete the catalogue.

The catalogue currently covers around 218 titles. It is a personal project and far from complete — these are starting points, not a definitive selection.

If you know a book that belongs here, please suggest it.

What belongs in this catalogue

  • Literature and non-fiction written in Portuguese — from Angola, Mozambique, Cape Verde, Brazil, São Tomé, Guinea-Bissau, Timor-Leste, Macau or Portugal
  • French-language academic works on Lusophone Africa
  • Available to buy (not rare manuscripts or out-of-print with no secondhand market)
  • Not already in the catalogue

The suggestion form opens on GitHub. You will need a free GitHub account to submit — the same place the catalogue's source code lives. All suggestions are public, so others can see them and add comments.

If you have an ISBN, please include it — it helps us link directly to the book page rather than just a search.
